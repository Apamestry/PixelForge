# frontend

Next.js (React) app — canvas editor (Fabric.js/Konva.js) and video timeline UI.

## Setup (run this once, from inside /frontend)
```bash
npx create-next-app@latest . --js --eslint --tailwind --app
npm install fabric        # or konva + react-konva
```

This folder is intentionally empty until `create-next-app` is run — don't commit
`node_modules/` (already covered by root `.gitignore`).
